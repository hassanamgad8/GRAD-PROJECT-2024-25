Option Descriptions

Option Description When to Use
Target URL The website to be scanned. Required for all scans.
Include Subdomains Scans subdomains of the target URL. Use when the target includes subdomains.
Custom Scope (Regex) Limits scans to specific URL patterns. Use when targeting specific file types (e.g., `.php`).
File Types Scans specific file types like `.php`, `.html`. Use for focused scanning.
SSL/TLS Certificate Validation Checks the validity and expiration of SSL/TLS certificates. Use to verify secure connections.
HTTP Security Header Validation Checks if proper security headers are configured. Use to enhance HTTP security.
CMS Identification Detects the CMS (e.g., WordPress, Joomla) used by the target website. Use to identify potential CMS-related vulnerabilities.
Directory Indexing Detects if directory indexing is enabled. Use to find unintended file disclosures.
File Upload Vulnerability Check Checks for insecure file upload functionality. Use to identify file upload risks.
Backup Files Discovery Searches for backup files left accessible on the server. Use to find exposed sensitive files.
CORS Misconfiguration Checks for improper CORS configurations. Use to ensure secure cross-origin communication.
Real-Time Logs Shows scan progress in real-time. Use for live feedback during scans.
Export Format Specifies the format for exportable reports. Choose based on your reporting needs.
