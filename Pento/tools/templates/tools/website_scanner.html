Option Descriptions

Option Description When to Use
Target URL The website to be scanned. Required for all scans.
Include Subdomains Scans subdomains of the target URL. Use when the target includes subdomains.
Custom Scope (Regex) Limits scans to specific URL patterns. Use when targeting specific file types (e.g., `.php`).
File Types Scans specific file types like `.php`, `.html`. Use for focused scanning.
WAF Bypass Attempts to bypass Web Application Firewalls. Use when scans are blocked by firewalls.
Injection Techniques Specifies SQL Injection techniques (Boolean, Error, Time-Based, Union). Choose based on the target database or vulnerability type.
Reflected XSS Tests for reflected XSS vulnerabilities. Use when inputs are immediately reflected in responses.
Stored XSS Tests for stored XSS vulnerabilities. Use when inputs are stored server-side (e.g., databases).
DOM-Based XSS Tests for client-side XSS vulnerabilities. Use when dynamic JavaScript manipulates the DOM.
Payload Encoding Encodes payloads (e.g., Base64, URL encoding). Use to bypass basic input filters.
Real-Time Logs Shows scan progress in real-time. Use for live feedback during scans.
Export Format Specifies the format for exportable reports. Choose based on your reporting needs.
