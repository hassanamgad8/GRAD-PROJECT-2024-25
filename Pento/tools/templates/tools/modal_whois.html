Option Descriptions

Option Description When to Use
Include Reverse Whois Lookup Searches for domains registered by the same entity. When investigating all domains owned by a single organization or individual.
Include DNS Records Fetches DNS records like A, MX, NS, and TXT. When you want to gather DNS information for further investigation.
Retrieve Historical Records Gets past Whois records if available. When tracking changes in domain ownership or details over time.
Include Geo-location Information Displays the geographical location of the domain or IP. When you need to identify the physical location of the entity.
Include Domain Age Calculates the age of the domain based on the creation date. When assessing the credibility or maturity of the domain.
Explain Domain Status Codes Provides detailed explanations of domain status codes. When you encounter unfamiliar status codes in the Whois data.
Output Format Specifies the format of the results (Plain Text, JSON, XML). Choose based on how you want to process or view the data.
