Subdomain Finder Options

Subdomain Finder Options Description

Option Description
Domain Specify the target domain for subdomain enumeration.
Enable Brute Force Perform DNS brute-forcing to discover additional subdomains.
Thread Count Set the number of threads to control the speed of the scan.
Resolve IP Addresses Resolve discovered subdomains to their corresponding IP addresses.
Exclude Subdomains Ignore specific subdomains by providing a comma-separated list.
Search Depth Define how deep Sublist3r searches for subdomains.
Generate Visualization Create a graphical representation of the discovered subdomains.
Quick Scan Perform a fast scan using minimal sources.
Comprehensive Scan Perform an in-depth scan using all available sources and brute-forcing.
Stealth Mode Slow down the scan to avoid detection or being blocked.
Save Results as TXT Save the output of the scan in a TXT file.
Save Results as CSV Save the output of the scan in a CSV file.
