Domain Finder Options Description

Option Description
Target Domain(s) Input one or more domains, CIDR ranges, or ASNs for scanning.
--include Limit results to in-scope domains.
--exclude Exclude specific subdomains or domains from the scan.
--passive Use only passive sources for stealth reconnaissance.
-active Enable active techniques like DNS brute-forcing and reverse lookups.
--brute Enable brute-force subdomain enumeration.
--wordlist Use a custom wordlist for brute-forcing subdomains.
DNS Records Retrieve DNS records such as A, CNAME, MX, and TXT.
IP Addresses Map subdomains to their corresponding IP addresses.
ASN and CIDR Identify associated ASNs and CIDR ranges for domains.
Recursive Enumeration Discover subdomains of already-discovered subdomains.
--alterations Enable typosquatting and domain permutations.
-T0 to -T5 Timing template to adjust scan speed and stealthiness.
Graph View Display subdomain relationships in a graph view.
Tree View Display subdomain relationships in a tree view.
Profiles Predefined scan modes such as Quick Scan, Comprehensive Scan, Brute Force Mode, and Stealth Mode.
