Port Scanner Options Description

        

            
                

                    Option
                    Description
                

            
            
                

                    -Pn
                    Disables host discovery; assumes all hosts are up.
                

                

                    -sn
                    Ping scan; checks which hosts are online without scanning ports.
                

                

                    -n
                    Disables DNS resolution for faster scans.
                

                

                    -R
                    Forces DNS resolution even for downed hosts.
                

                

                    -F
                    Performs a quick scan on the top 1000 commonly used ports.
                

                

                    -p-
                    Scans all 65535 ports.
                

                

                    -sT
                    Performs a TCP connect scan.
                

                

                    -sS
                    Performs a SYN scan, also known as stealth scan.
                

                

                    -sU
                    Performs a UDP scan.
                

                

                    -sN
                    Stealth scan; no TCP flags set.
                

                

                    -sF
                    FIN scan; only the FIN TCP flag is set.
                

                

                    -sV
                    Detects version information of services.
                

                

                    -O
                    Detects the operating system of the target.
                

                

                    -A
                    Combines OS detection, version detection, and traceroute.
                

                

                    -T0 to -T5
                    Specifies the timing template (from slowest to fastest).
                

                

                    -f
                    Fragments packets to evade firewalls.
                

                

                    --randomize-hosts
                    Randomizes the scan order of hosts.
                

                

                    -oN, -oX
                    Specifies output formats (Normal and XML).
                

                

                    --script
                    Specifies scripts for advanced scanning.
